# App shell

Updated: 2026-09-13.

`PromptManagerApp` defines the SwiftUI application scene and commands. `AppShellView` and `WindowConfigurator` implement the macOS window shell. Core views live in the `PromptManagerCore` module. Build with SwiftPM; bundle resources and packaging are separate from the core check executable.

Source: [PromptManagerApp.swift](../../Sources/PromptManager/PromptManagerApp.swift).
